# Assets Folder

This folder contains all static assets for the Solvia Labs website.

## Structure

- `images/` - All image files (logos, hero images, icons, etc.)
- `favicon.ico` - Website favicon
- `fonts/` - Custom font files (if any)

## Image Guidelines

- Use WebP format for better performance when possible
- Optimize images for web (compress without losing quality)
- Include both regular and retina (@2x) versions for high-DPI displays
- Recommended sizes:
  - Hero image: 1200x800px
  - Service icons: 64x64px
  - Logo: 200x60px
  - Favicon: 32x32px

## File Naming Convention

- Use lowercase letters
- Use hyphens to separate words
- Be descriptive: `hero-image.jpg`, `service-development-icon.svg`
